# Personal Portfolio

A responsive personal portfolio website built using **HTML** and **CSS** to showcase my skills, projects, services, and programming journey.

This portfolio highlights my experience, featured projects, technical skills, and provides an easy way to connect with me.

---

## Features

- Hero section with introduction
- About Me section
- Statistics section
- Technical skills showcase
- Services section
- Featured projects
- Frequently Asked Questions
- Contact section
- Responsive layout
- Modern and clean user interface
- Fixed navigation bar

---

## Technologies Used

- HTML5
- CSS3
